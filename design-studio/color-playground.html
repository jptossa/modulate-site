Semantic roles · Light roles

Each mode has its own set of roles, stored as CSS custom properties. The Light / Dark toggle chooses which set you edit and which the contrast checker runs on. In both modes, primary, secondary and accent follow the base color and harmony (dark mode lifts them to hold contrast on dark surfaces). In light mode, editing primary moves the base color; editing secondary or accent directly holds until the base or harmony next changes. Everything else is set by hand.

Contrast checker · Light mode

WCAG contrast ratios for the color pairs in the sample interface, for whichever mode is selected in the Light / Dark toggle. It re-checks whenever a role changes.
