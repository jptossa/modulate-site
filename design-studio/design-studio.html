Color roles (design tokens)

Every colour token in the app, one set per mode. The Light / Dark pill above the preview chooses which set you edit and which the contrast checker runs on. Changes apply to the preview immediately. Editing blue in Light moves the base colour. Base or harmony changes overwrite the blue and coral tokens in both modes.

Fonts

Base unit

One number sets the spacing of the whole page. Every padding, gap and margin in the components is multiplied by base unit ÷ 8, in every view. At 8 you get the app as shipped.

Page grid

The card rows (stat tiles, route options, detail cards, data sources) snap to this grid, and the page content sits inside the margin and maximum width. Medium widths use two thirds of the columns and narrow widths one third (12 becomes 8 and 4).

Responsive behaviour

The width of the preview decides the layout. Regular uses the studio window, Mobile is 390px, Print is the sheet, and Desktop is the width below.

Mode

Every token in one table, edited against the real components. Colours, type and the maximum width share their state with the other tabs. Rows marked proposed are new tokens from the token cascade that the app does not have yet.

Tokens (CSS)

Every token in this tab at its current value, in both modes, plus the page grid and responsive settings from the Layout tab. Values you changed are marked edited. This is exactly what Copy all tokens as CSS copies; Copy edited only copies just the values you changed.

    View-only link
    

      
The link carries every change you have made (type, colours, layout and tokens, plus the current view and mode) inside the address. Nothing is uploaded or stored. Whoever opens it sees the same preview and cannot change the values, but can open a copy to edit.

      

      

      
    

  

  

    Saved themes
    

      
Saved in this browser's local storage, on this device only. Only people using this browser profile can see them, and they are never uploaded. A theme holds your type, colour, layout and token changes, not the view or mode.
